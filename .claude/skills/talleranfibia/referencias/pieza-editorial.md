# Referencia · Pieza editorial

Textos largos para leer, presentados con cuidado tipográfico. Sin pop-ups, sin cookies, sin publicidad, sin distracciones. **Una pieza editorial es lo opuesto a un sitio comercial: prioriza la lectura.**

**Casos típicos**: una periodista gastronómica que reúne crónicas y recetas · un periodista financiero que relanza su plataforma · una historiadora del arte con un ensayo largo · una becaria que convierte un capítulo de tesis en algo legible · una escritora armando una pieza-newsletter · una activista con un dossier sobre cambio climático.

---

## 1 · Entender el material

1. **"¿Cuánto texto tenés?"** Una pieza, varias, un solo texto largo. Cambia la arquitectura.
2. **"¿Está escrito o lo vas a escribir mientras armamos?"** Si no está, **hay que parar y escribir primero**.
3. **"¿Tiene imágenes, audio, video?"** Define si es texto puro o multimedia editorial.
4. **"¿Quién es el lector ideal?"** Otros profesionales, lectores generales, suscriptores fieles.
5. **"¿Es para leer una vez o para volver?"** Pieza única vs. publicación continua.

---

## 2 · Formato

**A · Crónica larga** — un solo texto extenso (3.000-10.000 palabras). Ritmo de lectura controlado. Una sola URL.

**B · Especial / dossier** — varios textos sobre un tema. Página índice + subpáginas. Tres niveles máximo.

**C · Ensayo personal** — reflexivo, primera persona, mediano (1.000-3.000 palabras). Estética íntima.

**D · Archivo de piezas** — textos sin relación directa, organizados por fecha o tema. Como un blog pero editorial.

**E · Newsletter** — estructura serial, cada número autocontenido.

---

## 3 · La tipografía es el 70% de la estética

En una pieza editorial, esta es **la decisión más importante**. Dedicá tiempo.

**Cuerpo de texto** (lo crítico): **Fraunces** (serif moderna con personalidad) · **EB Garamond** (clásica, sobria) · **Source Serif Pro** (muy legible, neutra) · **Crimson Pro** (académica) · **Lora** (amigable, contemporánea).

**Títulos**: Fraunces con peso variable y `opsz` alto queda hermosa · PT Serif bold · cualquier display serif fuerte (DM Serif Display, Tenor Sans).

**Metadata** (créditos, fechas): Inter o IBM Plex Sans en tamaño chico. O una mono si querés estética más editorial (JetBrains Mono, Space Mono).

Probá combinaciones. Una pieza bien tipografiada es indistinguible de una revista de calidad.

### Los números que importan

- **Serif para cuerpo de texto.** No negociable.
- **60-75 caracteres por línea.** Es el óptimo de lectura.
- **Interlineado 1.6-1.8.**
- **18-22px** para cuerpo.
- Paleta sobria: blanco/crema/papel + negro/carbón + un acento ocasional.
- **Fondo claro por default.** La lectura larga lo prefiere; el modo oscuro va como opción, no como default.

**NO en estética editorial**: Inter genérica · gradientes · cards rounded · bento boxes · botones CTA llamativos dentro de la lectura · pop-ups u overlays · animaciones decorativas durante el scroll.

## 4 · Layout

```
+-------------------------------------------+
|  KICKER, SECCIÓN O CATEGORÍA              |
|                                           |
|  TÍTULO GRANDE                            |
|  Bajada o subtítulo en cursiva            |
|                                           |
|  Por Autor · Fecha · Tiempo de lectura    |
+-------------------------------------------+
|  [opcional: imagen destacada]             |
|                                           |
|  Primer párrafo más grande, como          |
|  introducción literaria. El lector        |
|  entra acá.                               |
|                                           |
|  Resto del texto en tamaño normal.        |
|  Párrafos con espacio amplio.             |
|                                           |
|  "Una cita destacada tipográficamente     |
|   en el medio del texto."                 |
|                                           |
+-------------------------------------------+
|  Pie de página austero.                   |
+-------------------------------------------+
```

Una sola columna. Ancho máximo cómodo. **Nunca texto edge-to-edge.**

---

## 5 · Los detalles editoriales

Estos gestos son los que dan identidad inmediata:

- **Dropcap** en el primer párrafo. Clásico, y se nota.
- **Pull quotes** con estilo propio: tamaño grande, sangría, color o tipografía distinta.
- **Notas al margen o al pie** si la pieza es académica o referencial.
- **Separadores tipográficos** entre secciones (asteriscos, líneas finas). Espacios de respiro.
- **Tiempo estimado de lectura** al principio. Gesto editorial cuidado.
- **Captions propios** en las imágenes. El caption es texto editorial, no "img-001.jpg". Con crédito de foto si corresponde.

Si hay audio o video: embebidos sobrios, sin players agresivos, y **transcripción disponible** (gesto periodístico cuidado).

---

## 6 · Lo que no se ve pero importa

- **`<title>`**: título de la pieza + nombre del autor.
- **`<meta description>`**: la bajada.
- **Open Graph tags**: para que se vea bien al compartir.
- **Schema.org Article**: para SEO editorial.
- **CSS de impresión**: algunos lectores imprimen para leer offline. Que quede bien.
- **Lazy load** en imágenes, texto primero.

---

## Reglas propias de este formato

- **Serif para cuerpo.** No negociable.
- **Ancho de columna controlado.** Cero edge-to-edge.
- **Cero pop-ups, overlays, banners o CTAs en medio de la lectura.**
- **Cero animaciones de scroll** que distraigan.
- **Si el texto no está escrito, no se construye.**
- Mobile-first, priorizando experiencia de lectura.

---

## Tono y cierre

Como **editor con autor**: respeto al texto, pero capacidad de sugerir. Si el texto tiene problemas (muy largo, sin estructura), sugerí cambios con tacto. Validá las decisiones autorales fuertes: es su pieza.

Una pieza editorial bien hecha **se distingue de un sitio comercial por lo que *no* hace**: no vende, no interrumpe, no exige, no acelera. En un mundo digital lleno de fricción, es un acto de hospitalidad: el lector llega y le ofrecemos un sillón, buena luz, un café y silencio.

Empujá al alumno a confiar en su texto. Si el texto es bueno, la estética solo tiene que no estorbar. **Si la estética grita más que el texto, falló.**

Cuando terminen, pedíle que la lea entera, en voz alta, una vez. Si suena bien, está bien.
